# MCP 协议与工具

## 当前协议范围

当前 MVP 直接实现最小 JSON-RPC MCP handler：

- `initialize`
- `tools/list`
- `tools/call`

`tools/list` 只返回 admin 页面中启用的工具；禁用的工具即使被直接调用也会返回错误。

服务入口：

- `POST /mcp`

如果设置了 `MCP_DEV_TOKEN`，请求必须带：

```http
Authorization: Bearer <MCP_DEV_TOKEN>
```

## 工具清单

### `ping`

用途：验证 ChatGPT 或 curl 能成功调用 MCP 工具。

输入：

```json
{
  "message": "optional"
}
```

### `create_preview`

用途：创建一个内存 job，并返回 `/outcome/<jobId>` 预览链接。

输入：

```json
{
  "title": "MVP Preview",
  "summary": "Runtime verification preview."
}
```

### `write_file`

用途：在 `WORKSPACE_ROOT` 内写入 UTF-8 文件。

限制：

- 禁止绝对路径
- 禁止 `..`
- 禁止隐藏路径片段（例如 `.env`、`.git/config`）
- 内容最大 256 KiB

输入：

```json
{
  "relativePath": "generated/example.txt",
  "content": "hello"
}
```

### `run_command`

用途：执行白名单 npm 命令。

允许命令：

- `npm test`
- `npm run build`
- `npm run typecheck`

输入：

```json
{
  "command": "npm run typecheck"
}
```

### `list_dir`

用途：列出工作区目录与文件。

输入：

```json
{
  "relativePath": ".",
  "recursive": false,
  "maxDepth": 2,
  "includeHidden": false
}
```

### `read_file`

用途：读取工作区 UTF-8 文件内容。

输入：

```json
{
  "relativePath": "src/server.ts",
  "maxBytes": 65536
}
```

### `search_files`

用途：按文本或正则搜索工作区文本文件。

输入：

```json
{
  "query": "runCommandInputSchema",
  "path": "src",
  "useRegex": false,
  "caseSensitive": false,
  "maxResults": 100,
  "maxDepth": 4,
  "includeHidden": false
}
```

### `git_status`

用途：查看工作区 git 状态摘要。

输入：

```json
{}
```

### `git_diff`

用途：查看 git diff，可选只看暂存区或指定路径。

输入：

```json
{
  "cached": false,
  "path": "src/server.ts"
}
```

### `replace_in_file`

用途：在单文件内查找并替换文本（可选替换全部）。

输入：

```json
{
  "relativePath": "src/server.ts",
  "find": "oldText",
  "replace": "newText",
  "all": false
}
```

### `delete_file`

用途：删除工作区文件（需显式 `confirm` 确认）。

输入：

```json
{
  "relativePath": "tmp/demo.txt",
  "confirm": true
}
```

### `rename_file`

用途：重命名或移动文件。

输入：

```json
{
  "from": "tmp/demo.txt",
  "to": "tmp/archive/demo.txt",
  "overwrite": false
}
```

### `file_info`

用途：读取文件元信息（大小、时间戳、类型）。

输入：

```json
{
  "relativePath": "src/server.ts"
}
```

### `git_log`

用途：查看最近提交记录，可指定路径与数量。

输入：

```json
{
  "maxCount": 20,
  "path": "src"
}
```

### `create_directory`

用途：创建目录（支持递归）。

输入：

```json
{
  "relativePath": "tmp/reports",
  "recursive": true
}
```

### `tail_file`

用途：读取文件尾部日志。

输入：

```json
{
  "relativePath": "dist/server.js",
  "maxLines": 120,
  "maxBytes": 65536
}
```

### `create_share`

用途：发布一个独立 HTML 页面，并返回公开分享链接。

输出链接格式：

```text
https://gmb01.xyz/share/{id}/{filename}.html
```

限制：

- 只接受 `.html` 文件名
- 文件名只能包含小写字母、数字、点、下划线和 dash
- HTML 内容最大 1 MiB
- 产物保存在 `SHARE_ROOT`，默认 `.shares`
- 当前 share registry 是内存索引，服务重启后旧链接不会被索引；下一阶段可改成磁盘扫描或数据库持久化

输入：

```json
{
  "title": "Demo Project",
  "summary": "Standalone HTML page generated by ChatGPT through MCP.",
  "filename": "index.html",
  "html": "<!doctype html><html><body><h1>Hello</h1></body></html>"
}
```

## curl 示例

```bash
curl -sS -X POST http://127.0.0.1:6859/mcp \
  -H "content-type: application/json" \
  -H "authorization: Bearer $MCP_DEV_TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

```bash
curl -sS -X POST http://127.0.0.1:6859/mcp \
  -H "content-type: application/json" \
  -H "authorization: Bearer $MCP_DEV_TOKEN" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"create_preview","arguments":{"title":"MVP Preview","summary":"Runtime verification preview."}}}'
```
